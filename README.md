# Nexon AI

Nexon AI is an advanced Android assistant designed to manage media playback and deliver responsive AI-powered information retrieval.

## Features
- **Real AI Inference**: Configurable HTTPS endpoint support for OpenAI or compatible backends.
- **Media Management**: Local audio device scanning and playback controls.
- **Zero Hardcoded Secrets**: All keys and configuration parameters are entered securely at runtime.

## Configuration
1. Open the app and navigate to the **Settings** tab.
2. Enter your HTTPS Backend URL and API Key.
3. Save configuration to begin querying Nexon AI.
